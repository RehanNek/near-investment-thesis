# v1 (frozen 2026-11-11)

A frozen copy of the second version of the thesis. A shorter v2 was tried on 2026-11-11, and on 2026-11-12 v3
was built from v2; v3 is the version at the repo root. This copy is not rebuilt by `make charts`; the numbers
are the data as of Nov 6, 2026.

- `THESIS.md`: a memo in plain English, then claims C1–C6 each with evidence for, evidence against and what would
  change our mind, then an eight-part appendix.
- `DASHBOARD.md`: every chart with one plain sentence and the query behind it.
- `site/index.html`: the same dashboard with hover readouts (open it in a browser; the code links point back to the repo).
- `viz/`: the build code and template that produced them.
- `data/headline_numbers.json`: every number quoted in v1.

The first version is in `../v0/`, and v2 is in `../v2/`.
