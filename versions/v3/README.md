# v3 (frozen 2026-11-14)

The version built from v2 on 2026-11-12, with the thesis line "NEAR isn't just an L1 anymore. It's a three-layer
business, and the token is only beginning to capture that value." On 2026-11-14 the thesis line was replaced and
this version was frozen so nothing is lost. It is not rebuilt by `make charts`; the numbers are the data as of
Nov 6, 2026.

- `THESIS.md`: the thesis paragraph, the problem NEAR solves, the three layers, why the token has value, the last
  year business by business, and one table per claim: for, against, what would change our mind.
- `METHODS.md`: how each number is computed, each claim's evidence in detail, scenarios, sources.
- `DASHBOARD.md`: every chart with one plain sentence and the query behind it.
- `site/index.html`: the same dashboard with hover readouts (open it in a browser; the code links point back to the repo).
- `viz/`: the build code and templates that produced them.
- `data/headline_numbers.json`: every number quoted in v3.

The current version is v6 (v5 is in `../v5/`, v4 in `../v4/`): `THESIS.md`, `METHODS.md` and `DASHBOARD.md` at the repo root. Earlier versions are in
`../v2/`, `../v1/` and `../v0/`.
